# Real-Estate-Price-Predictor

# 🏡 Melbourne Housing Price Prediction

🚀 **Predicting house prices in Melbourne using Machine Learning!**  
This project explores house price predictions using **Decision Tree Regressor** and **EDA (Exploratory Data Analysis).**  

---

## 📌 Project Overview  
The goal of this project is to build a **Machine Learning model** that predicts house prices based on key features such as location, number of rooms, land size, and year built.  

✅ **Steps Taken:**  
- **Data Cleaning** – Handled missing values and dropped irrelevant features.  
- **Exploratory Data Analysis (EDA)** – Visualized patterns in house prices.  
- **Feature Engineering** – Added `YearBuilt` to improve model accuracy.  
- **Model Training** – Used `DecisionTreeRegressor` from Scikit-Learn.  
- **Evaluation** – Checked the model’s accuracy using `Mean Absolute Error (MAE)`.  

---

## 📊 Dataset  
The dataset used in this project is the **Melbourne Housing Dataset**, containing details of properties sold in Melbourne, Australia.  

🔹 **Key Features Used:**  
- `Rooms` – Number of rooms  
- `Bathroom` – Number of bathrooms  
- `Landsize` – Size of the property  
- `YearBuilt` – Year the house was built  
- `Price` – Target variable (House price)
